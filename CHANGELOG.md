# Changelog

## Unreleased

The first steps of Menew for Windows.

- **Command palette** with <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>Space</kbd> or a click on the tray icon: find and open your apps (Start menu and Store apps) and do math (`12*7.5`, `20% of 340`, `200 + 10%`), with <kbd>Enter</kbd> copying the result.
- **Tray icon** with Open palette and Quit. Menew runs once: starting it again opens the palette.
- **Automatic updates**, like the Mac app: Menew checks GitHub once a day, downloads new versions in the background and installs them the next time it starts, or right away from the tray menu. Install it with `winget install Pururucos.Menew` or the installer from the GitHub release.
- The interface in English, Portuguese, German, Spanish and Chinese, following the Windows display language.
